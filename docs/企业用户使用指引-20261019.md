# 企业用户使用指引 · 出海合规雷达（chat1.6）

> 这份指引写给第一次使用这个工具的业务同学。读完大概 3 分钟，照着走一遍就能上手。
> 工具帮你**查清要求、排出下一步**，但它不构成法律意见；最终结论请交给法务或合规负责人确认。

---

## 一、它到底帮你做什么

你输入「卖什么 + 卖到哪个市场」，它输出四样东西：

1. **适用法规清单** —— 这个品类、这个市场，通常要看哪些法规。
2. **变化与关键日期** —— 最近有没有新规、什么时候生效、有没有过渡期。
3. **可执行的待办** —— 按阶段拆成能直接动手的事。
4. **原文出处** —— 每条结论都带官方链接，可以自己点开核对。

它不会替你拍板说「一定合规」。凡是需要专业判断的地方，它会标成「待确认」。

---

## 二、三步开始（第一次用）

**第 1 步 · 一句话说清生意**

在底部输入框直接写，例如：

```
我想把毛绒玩具卖到德国亚马逊，从哪里开始？
```

不用先选菜单，也不用写得像公文。带上「品类 + 市场 + 平台」三要素，结果最准。

**第 2 步 · 回答它的追问**

它一次只问一个条件，比如「适用年龄」「是否带电」「FBA 还是自行发货」。
不知道怎么回答就选「**暂不确定**」——它会保留这个未知项，而不是替你猜。

**第 3 步 · 看行动，点依据**

- 「**现在先核对这几项**」：最多三条最该先做的事。
- 点开「六阶段」：选品 → 合规 → 认证 → 上架 → 履约 → 售后，逐阶段看任务。
- 点「**依据与官方原文**」：看这条建议来自哪部法规、哪个链接。
- 做完一项可以点「我已准备此项」——这只会记成「**用户自述完成**」，不等于通过审核。

## 三、七个功能怎么用

| 你想做的事 | 怎么说 / 点哪里 |
|---|---|
| 看某品类要遵守哪些法规 | 「儿童玩具卖到欧盟，相关法规有哪些」或点「相关法规」 |
| 排出最近的待办 | 「先看合规待办」 |
| 查法规生效与变化时间 | 「查看法规变化时间线」 |
| 比较两个市场 | 「比较欧盟和美国的儿童玩具法规目录」 |
| 一次看多个市场 | 「多个市场汇总」 |
| 准备上线 | 「整理上线准备计划」 |
| 看回答方法与来源差异 | 「查看模型对照」 |

第一次进来时，首页的六张卡片就是最常用的六个入口，点一下即可。

## 四、查条款原文（最常用的深度功能）

展开底部「**资料覆盖、来源与条款检索**」，在「按法规编号检索条款」里输入法规编号：

- `32009L0048` —— 欧盟玩具安全指令
- `32023R0988` —— 通用产品安全法规（GPSR）

点「检索已有条款」，会显示正文切片、所属法规、官方 EUR-Lex 链接和抽取状态。
**看到「数据库已接入」不等于法律审核完成**，正文要自己读，适用性要按你的产品确认。

---

## 五、语音输入

展开「**语音输入 · 转写后确认再发送**」：

1. 上传或录一段语音，点「转写到输入框」。
2. 文字会进入输入框，并标注 `预编辑 · 未提交`；此时**还没有发起任何查询**。
3. 核对产品名、市场、数字，改错字。
4. 没问题再点「发送」。
5. 想退回原话就点「**撤销识别**」：没改过会还原原文，改过则保留你的修改。

建议：嘈杂环境或专业术语多时，手动检查一遍再发送，别直接发。

---

## 六、导出与历史

- 输入「先看合规待办」后，点「生成当前结果的导出文件」，再点「下载这份结果」得到 CSV。
- 导出的 CSV 可以直接发给采购、法务或货代。
- 点「历史结果」可以回到之前某次查询，条件会一起保留。

## 七、常见问题

**Q：为什么它总问我年龄、是否带电？**
A：这两项直接决定适用哪套玩具安全要求和认证路径。缺这两项，结论就没法收敛。

**Q：为什么不说「已合规」？**
A：合规结论要结合你的实际产品、检测报告和平台规则，机器只能给出「通常需要关注什么」。所以它把完成状态记成「用户自述」，把不确定项标成「待确认」。

**Q：结果能直接给客户或平台看吗？**
A：可以给内部使用。对外请附上原文链接与法务复核意见，避免把「机器整理的资料」当成「法律意见」。

**Q：法规库多久更新一次？**
A：以页面顶部显示的「数据截止时间」为准。看到更晚的官方修订，请以官方原文为准并反馈给我们。

---

## 八、和法务协作的推荐姿势

1. 用工具跑出清单和待办，导出 CSV。
2. 把「待确认」项单独列一页，标注产品实际参数。
3. 让法务只复核这些条目，而不是从零查法规。
4. 复核结论写回 CSV 的备注列，留有核对人和日期。

这样一份「机器初筛 + 人工确认」的记录，比一句「AI 说没问题」可靠得多。
