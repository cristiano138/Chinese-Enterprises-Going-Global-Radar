## 演示顺序

1. 在聊天框输入“我想把毛绒玩具卖到德国亚马逊，从哪里开始？”。
2. 按实际产品回答年龄、是否带电、FBA/自行发货；不清楚的条件选“暂不确定”。
3. 查看当前优先事项，展开六阶段任务及“依据与官方原文”；记录完成时确认这是用户自述。
4. 展开“资料覆盖、来源与条款检索”，输入 `32009L0048` 或 `32023R0988`，查看正文切片及官方来源。
5. 输入“先看合规待办”，使用导出控制下载 CSV，随后继续查询或切换历史结果。
6. 可选上传一段自愿用于演示的短语音，核对预编辑文字后发送；“撤销识别”恢复未改动的识别结果，手动修正的文字会保留。
