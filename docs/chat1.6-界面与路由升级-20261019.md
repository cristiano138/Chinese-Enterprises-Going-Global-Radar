# chat1.6：助手式首页、开场动画与路由修复

本轮在 chat1.5 基础上做界面与链路的升级，应用代码提交 `9e2bdff`（GitHub main），魔搭部署提交 `8304fd7`（master），构建分支 `bfb30ea`，镜像 `369712-bfb30ea6-2026-10-19-20-22-53`，20:30 起 Running。

## 一、界面

1. **助手式首页**：顶部是头像与在线状态，中间是「我是合规雷达」问候，下面是六张建议卡片（玩具→德国、玩具→欧盟、欧美对照、时间线、多市场、上线准备），底部是输入框。
2. **开场动画**：品牌块 + 雷达扫描 + 进度条，约 1.8 秒自动淡出；可点「跳过开场」，`prefers-reduced-motion` 下直接不播放。
3. **新手教程**：首页常驻「新手教程 · 4 步用好这个助手」，讲清说清生意 → 回答追问 → 看行动与依据 → 查正文/导出/存档。
4. **自适应**：建议卡片与教程在窄屏自动单列，输入框吸底，手机端无横向滚动。

## 二、链路

- **路由器接入 DeepSeek**：`MODEL_API_BASE=https://api.deepseek.com/v1`、`MODEL_NAME=deepseek-chat`。密钥只写在本机 `.env`（已被 `.gitignore` 排除），不进仓库、不进日志。
- **修复 thinking 参数**：此前默认给所有模型传 `thinking=enabled`，`deepseek-chat` 会返回空内容或截断（实测 900/1500 tokens 时返回 0 字符）。现在按模型名自动判断，只有推理类模型才开启。
- **合入 PR #5**：召回目录树 + 两层召回 + 材料落库链路 + 数据治理工具集；修正了其中三处项目根目录解析（原先指向工作区上一级）。
- **M4 真实回放**：录制了同题同日的真实对照（`data/m4_replays.jsonl`），通用侧为 deepseek-chat 原始回答，工具侧为系统实际输出，含来源覆盖与核验结论。
