# 微信传输与恢复说明

这是完整数据库的无损分包，不是按法规划分的独立数据库。请发送全部5个 regulations_full_*.zip 文件，每个都小于500MB。

## 接收方操作（Windows）

1. 下载全部5个 ZIP，保存到电脑。不要只在微信内预览。
2. 将5个 ZIP 全部解压到同一个空文件夹。不要保留5层各自独立的子文件夹。重复的说明文件、manifest.json、restore_database.cmd 内容相同，保留一份即可。
3. 确认该文件夹内有 regulations.sqlite3.part001 至 part005 共5个分片，以及 manifest.json、restore_database.cmd。
4. 确保还有至少3GB可用空间，双击 restore_database.cmd。它会先校验各分片，再恢复数据库并检查完整文件的 SHA256。
5. 出现 SUCCESS 后得到 regulations.sqlite3。原始 ZIP 和分片不会自动删除，可自行选择保留哪些副本。

恢复工具只处理同一文件夹内的分片，不联网、不安装软件、不需要管理员权限；已有同名数据库时会停止，不会覆盖。

单个分片无法作为 SQLite 打开。恢复后的完整库约2.1GB，需要 SQLite 工具读取，不能按文本文件打开。日常查看请优先使用另行提供的轻量数据库或 Markdown 阅读版。

若提示 MISSING，请检查是否漏下分包、解压到不同文件夹；若提示校验失败，请重新下载对应分包。恢复失败时不要使用残留的输出文件。

其他系统也可按001至005的顺序二进制拼接，并与 manifest.json 中 original_sha256 比较。任何转换为Excel、CSV的方式都不能等价保留完整数据库及原始文件。
