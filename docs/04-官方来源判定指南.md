# EUR-Lex「官方来源」判定指南

> 用途：让全队统一「什么算官方来源」——**每条结论后面必须挂的那个链接，长什么样**。

> 配套：`语料核对表.xlsx`（同目录）

## 一、一句话结论

**域名是 `eur-lex.europa.eu`（或官方 ELI 永久标识 `data.europa.eu/eli/...`）、能定位到《欧盟官方公报》上的法条原文、并且有 CELEX 号 + ELI 标识的，才叫「官方来源」。**

三个条件缺一不可：

| 要素       | 判定                                                                                    |
| -------- | ------------------------------------------------------------------------------------- |
| **① 域名** | 必须是 `eur-lex.europa.eu`；ELI 永久链接可为 `data.europa.eu/eli/...`。出现律所站、聚合库、百科、AI 摘要站 → 非官方 |
| **② 法源** | 落在《欧盟官方公报》**Official Journal（OJ）**&#x4E0A;公布的文本 → 才是正式法源                              |
| **③ 标识** | 页面能找到 **CELEX 号** 与 **ELI 标识**，且编号能对回 OJ → 可核验、可引用                                    |

## 二、EUR-Lex 是谁

- EUR-Lex 是**欧盟法律的官方门户**，由**欧盟出版局（Publications Office of the European Union）**&#x8FD0;营，网址 `eur-lex.europa.eu`。
- 提供 24 种欧盟官方语言版本；**各语言版本的 OJ 文本同等作准**。
- 电子版 OJ 可回溯到 1952-12-30（煤钢共同体第一期官方公报）。

## 三、《欧盟官方公报》OJ —— 正式法源在哪

- OJ 是欧盟法令与其他官方信息的**官方公报（gazette）**，周一至周五出版（紧急情况含周末）。
- 分两辑：

| 辑别      | 名称                             | 装什么                                               | 与本项目           |
| ------- | ------------------------------ | ------------------------------------------------- | -------------- |
| **L 辑** | Legislation（立法）                | 条例 Regulation、指令 Directive、决定 Decision、意见、建议、国际协定 | **三个类目的法规都在这** |
| **C 辑** | Information and notices（信息与通告） | 准备性文件、通告、判决摘要、年报、招标等                              | 一般不作法规原文引用     |

- **效力关键点**：**自 2013-07-01 起，只有 EUR-Lex 上的电子版 OJ（e-OJ）具有法律效力**（依据 Council Regulation (EU) No 216/2013）；**纸质版不再具法律效力**（极端情况下才例外）。
- e-OJ 带**电子签名**，可用欧盟官方 **CheckLex** 工具验证真伪。
- 2023-10-01 起，OJ 不再是一期合订本，**每个法令单独作为一份 OJ 以 PDF 发布**。

## 四、两种"版本"，别搞混（核对时最容易出错的地方）

| 文本                        | 说明                         | 能不能当权威引用                                  |
| ------------------------- | -------------------------- | ----------------------------------------- |
| **官方原文（OJ 版）**            | 在 OJ 上公布的那一版原文             | ✅ 权威文本，**引用以它为准**                         |
| **整合版 Consolidated text** | EUR-Lex 把历次修订**合并**后的便利阅读版 | ⚠️ 仅便于查阅，**非权威文本**；只能当"定位线索"，结论仍回 OJ 原文核对 |

> 本项目 M2「近期变化」尤其要注意：**"现行要求"要引整合版时，必须同时能指到 OJ 原文/修订法令**，不要把整合版当成唯一依据。

## 五、拿官方链接的标准动作（30 秒）

1. 打开 `eur-lex.europa.eu`。
2. 用首页 **"Find results by CELEX number"** 输入 CELEX 号（例：`32023R0988`）直接跳到该法令；或 **Advanced search** 按关键词+类目搜。
3. 进入文档页，**复制浏览器地址栏的 ELI 链接**——它就是「官方链接」。
4. 在该页取：官方标题、CELEX 号、OJ 出处（L 辑期号/日期/页码）、生效日期。

## 六、标识体系速查（写进核对表的三列）

**CELEX 号** —— EUR-Lex 上每个文档的唯一编号，形如 `32006L0121`  
`sector 位 + 年份(4) + 类型字母 + 年度流水号`

- 首位 `3` = 派生立法（条例/指令/决定等，最常用）
- 类型字母：`R`=条例 Regulation、`L`=指令 Directive、`D`=决定 Decision
- 例：`32023R0988` = 2023 年第 988 号条例（GPSR）；`32009L0048` = 2009 年第 48 号指令（玩具安全）

**ELI 永久标识** —— European Legislation Identifier，稳定、机器可读的引用标识  
标准结构：`http://data.europa.eu/eli/{类型}/{通过年份}/{编号}/oj`

- 类型码：`reg` 条例 / `dir` 指令 / `dec` 决定
- 例：`eur-lex.europa.eu/eli/reg/2023/988/oj`、`eur-lex.europa.eu/eli/dir/2009/48/oj`
- 可细到条款：`.../eli/reg/2019/1241/art_2/oj`

**官方编号** —— OJ 里的法令编号  
`类型缩写括号（EU / Euratom / CFSP）+ 4 位年份 + 年度流水号`

- 例：`Regulation (EU) 2016/1036`、`Directive 2009/48/EC`、`Decision 2009/496/EC`
- 该流水号同时就是它在 OJ 中的编号

## 七、明确**不算**官方来源的（见到就标注）

| 情形                                                          | 怎么记                              |
| ----------------------------------------------------------- | -------------------------------- |
| 第三方法律数据库、律所/媒体解读、百科、AI 生成的摘要                                | 来源类型 = `非官方（第三方）`；是否官方来源 = `非官方` |
| EUR-Lex 的**摘要页**（summary / LEGISSUM）：在官方站，但是**解读性摘要、非法条原文** | 来源类型 = `官方摘要`（不可当原文引用）           |
| 无 CELEX / ELI、或点进去回不到 OJ 原文的链接                              | 不能作为官方来源                         |
