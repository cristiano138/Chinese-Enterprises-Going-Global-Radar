# 出海合规雷达：面向跨境卖家的法规查询与合规准备辅助工具

文档版本：v0.2｜编写日期：2026-10-16｜状态：**初稿，待团队讨论审核，还有一些过程性的证明和内容需要上传和确认**

v0.2 更新：智能判定响应提速（硬超时封顶 + 内存缓存 + 启动预热）；新增时效性监控最小可行版（官方链接定期核验 + 页脚徽章 + 日志留档，见 `docs/时效性监控.md`）。

[代码仓库](https://github.com/cristiano138/Chinese-Enterprises-Going-Global-Radar)｜[魔搭创空间体验入口](https://modelscope.cn/studios/zhanxy2551/ComplianceRadar)

出海合规雷达面向中小跨境卖家，支持业务描述和类目查询，帮助用户查找法规、查看日期和整理准备事项，并保留官方来源供后续核对和交接。项目第6版已在魔搭创空间上线，正在优化，准备发布后续版本。

## 一、目标场景

本项目以“儿童玩具×欧盟”为主演示场景：一位中国卖家准备向欧盟销售普通非电动玩具，需要了解哪些要求与自己有关，哪些现在应当关注，哪些属于未来变化，以及还需准备什么资料。

用户可以直接选择类目和市场，也可以输入“我想把玩具卖到欧盟，需要准备什么”。产品帮助用户查找依据和整理事项；适用年龄、材料、经营者身份及具体销售国家，仍需结合实际情况确认。

当前范围设置为欧盟、美国及五个业务类目：儿童玩具、电子电器、纺织服装、美妆个护、食品接触材料。各组合的数据审核和功能成熟度不同，不能将入口覆盖范围理解为全部法规已经收齐或全部商品已经能够判定。

## 二、用户痛点

卖家需要把分散在不同官方渠道的规则，转换成检测、标签、文件等实际准备工作。法规是否适用，往往取决于商品属性、经营角色和时间条件，单看法规名称并不足以作出判断。

例如，欧盟新玩具条例于2026年1月1日生效，主要规定自2030年8月1日适用。两个日期含义不同，不能仅看到“新规生效”就认定旧要求立即失效。[欧委会说明][S1]、[新条例第56、59条][S4]

通用AI已经能够搜索、解释法规并追问商品信息，但用户仍需检查依据是否支持具体建议，再整理成可执行事项。我们整理的[四份同题回答](四个AI大模型对于同一问题的回答.md)中，对欧盟责任主体、认证路径和新旧法规过渡存在不同表述。这些样本用于定位核验重点，不用于推断模型整体准确率。

欧委会2025年Safety Gate报告记录了4,671次危险非食品产品警示，其中玩具占16%。这说明玩具安全是持续受到监管关注的领域；警示构成不能解释为全部在售玩具的不合格率。[官方报告][S2]

## 三、产品方案与使用流程

产品围绕“查询后能够继续核对和准备”组织信息。程序从底表检索并关联法规编号和官方链接，模型用于理解输入及语言整理。条款解释和适用条件仍需人工复核，官方链接本身不能证明建议一定正确。

| 使用环节 | 用户操作及获得的内容 |
|---|---|
| 选择入口 | 通过类目、市场下拉查询；也可在M1.5输入一句业务描述，查看品类与市场识别结果、路由说明及资料提示 |
| 查看法规 | 在M1查看关联法规、官方编号和来源链接，回到官方页面核对 |
| 查看日期 | 在M2查看时间事件，关注生效、开始适用及过渡节点的区别 |
| 整理准备事项 | 在M3查看待办候选及来源；结合自己的身份和商品条件继续复核 |
| 导出交接 | 将待办导出为CSV，供团队、工厂或专业人员进一步核对 |

两种入口目前分别呈现，M1.5的资料提示尚未与M3形成完整的逐项映射。提示按类目整理，不代表系统已经检查用户文件或准确识别全部缺失材料。

我们希望进一步完善每项行动的条款依据、适用条件和执行时点，并将当前要求与未来准备分别展示。已有欧盟玩具人工差异案例可供复核，签核与产品接入仍待完成。M4用于保留同题真实回答并核验来源，目前仓库版本尚缺真实回放记录，不预设通用模型必然出错。

## 六、市场需求与商业模式

商务部网站转引海关数据：2024年我国跨境电商出口约2.15万亿元，主要出口目的国中美国占36.2%，德国占5.7%。[数据来源][S3] 项目拟服务缺少专职法规人员、需要整理合规准备资料的中小卖家；出口额用于说明业务背景，不能直接当作本产品的市场规模或收入预测。

商业模式拟先验证基础自查工具的使用价值，再探索面向企业的订阅服务，例如资料整理、复核记录和法规变化提示。对需要专业判断的事项，可研究与检测、法律等服务的衔接。付费意愿、服务定价和转化效果均待试用验证，当前不设收入预测，也不将合作方向写成已取得的成果。

## 七、落地及转化路径

近期以欧盟玩具为主，完善条款证据、日期解释、待办与导出，补充真实对照记录，并用线上版本演示验证。随后邀请实际卖家或相关从业者试用，观察其能否据此找到下一步要核对的事项、整理资料并完成交接，记录遗漏、不适用建议和重复整理成本。

「持续监控」已踏出第一步（团队新思路的可行性收敛）：官方链接定期核验脚本已上线，结果页展示最近核验时间，日志留档可回放；全文快照落库、线上定时触发、变更推送按 `docs/时效性监控.md` 的路线排进后续迭代。

根据试用结果，再选择资料缺口记录、限定范围的AI回答核验等方向。企业数据接入、权限管理和合同、BOM解析属于后续规划。

新增市场时，除接入官方数据源，还需完成类目、时间语义和适用条件审核。日本、韩国、英国、加拿大、澳大利亚、沙特及巴西是候选方向，具体顺序取决于需求、数据可得性和复核成本。

本清单仅供参考，不构成法律意见，请由专业人员复核。
