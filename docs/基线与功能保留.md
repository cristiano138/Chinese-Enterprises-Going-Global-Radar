## 数据边界

现有快照为 `v1.1`，数据截止字段归一展示为 `2026-10-14`；86 条记录中，欧盟 29 条标记“已核对”，美国 57 条标记“待核对”。部分记录本身已废止，查询输出保留其效力状态。这些数量是底表和快照的已有统计，不表示所有规定都已覆盖或截至今天重新核验。

`validate_corpus.py` 的基线结果为结构校验 `valid=true`，并明确 `release_eligible=false`：美国 57 条尚未人工核对。这个状态不会因 UI 改版或测试通过而变成“全部可用的合规结论”。M3 对美国儿童玩具返回零条可执行动作；M5/M6 仍可展示其有来源的候选法规并标记待核对，M7 保留部分可用状态。

本轮没有接入正式约 2 GiB SQLite 库。现有 `selftest_law_store.py` 使用测试夹具验证检索、缺库降级、候选入库一致性与备份等行为，不能据此声称历史正式库内容已检查。默认包不含库；未配库时正文检索提示原因，CSV 主链路仍可运行。
