1. 先查法规，再问“从哪里开始”时，旧逻辑会继续显示法规视图。现将“从哪开始 / 从哪里开始 / 如何开始”识别为行动路线，并加入回归检查；实际线上德国玩具路线通过。

## 浏览器验收方法与网络观察

平台定制 SDK 要求魔搭父页面环境。检查工具的 `--modelscope-embed` 模式提供空父框架，内部加载真实线上运行地址；应用 HTML、静态资源、业务请求与下载均来自线上空间。该模式用于主流程检查，不能单独证明门户正常，因此另行访问了未替换页面的真实魔搭门户并保存证据。

在已安装 Playwright 和 Chromium 的 Python 环境中，从正式根目录复现匿名主流程检查：

```powershell
python scripts/check_chat_browser.py --url https://zhanxy2551-complianceradar-v2.ms.show --modelscope-embed --output outputs/online-public-browser-chat13
```

最终通过的 30 项检查使用浏览器系统网络设置，无认证请求头，也未修改系统代理设置。线上不执行全局存储失效与初始化失败注入，因为这会先破坏平台 SDK；这两个场景的 4 项检查保留在先前通过的本地 34 项检查中，不计入本次线上结果。

早期强制直连时观察到平台网关 429、CDN 资源加载失败、`queue/data` 事件流 `net::ERR_ABORTED` 和查询等待超时；其中一次在导出后查询对比时超时，独立复核也曾在导出前失败，因此没有证据将其归因为导出代码缺陷。最终使用系统网络设置后，下载、后续查询和全部 30 项流程通过。没有据此宣称所有网络路径均已稳定，也没有把切换测试浏览器网络方式写成生产代码修复。`--direct-network` 仅供后续对照诊断。
