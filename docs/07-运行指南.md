## 1. 创建环境与启动

在PowerShell中执行；已有可用Python 3.11虚拟环境时跳过创建步骤：

```powershell
Set-Location -LiteralPath 'E:\workbuddy\2026-10-14-01-02-52\compliance-radar'
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

没有 `py` 时用本机Python 3.11完整路径；本机已安装 `uv`，也可执行 `uv venv --python 3.11 .venv` 和 `uv pip install --python .venv\Scripts\python.exe -r requirements.txt`。不要混用默认解释器与项目环境。

打开 `http://127.0.0.1:7860`。监听地址为 `0.0.0.0`，端口优先 `PORT`，其次 `SERVER_PORT`，默认7860。本地冲突可设置 `$env:PORT='7861'` 再启动；魔搭使用7860。

运行依赖为Python 3.11、Gradio 6.2.0及 `requirements.txt` 中其他依赖。启动无需重新抓取法规或填写模型密钥。主CSV、快照、`data/journey_sources.json`、`assets/`、完整 `core/` 与 `modules/` 必须存在。

## 2. 在聊天界面使用七项能力

输入“我想把儿童玩具卖到德国亚马逊”，按追问补充条件。也可打开“更多功能”，选择法规地图、变化时间线、合规待办、模型对照、区域差异、多市场汇总、OPC准备。目录与自然语言调用同一服务，任务和来源按需展开。

主路线为儿童玩具→德国→亚马逊德国站。准备阶段、带电属性、履约方式及已有材料影响建议，材料与完成进度属于用户自述，不能作为审核通过证据。其他范围保留原查询能力并说明缺口。美国57条待核对，不据此生成已核对的执行动作。

当前结果可以下载待办或准备清单CSV；更改产品或市场后，应生成新结果，再导出。历史结果保留原始条件，不允许静默导出为当前结果。新建对话清空当前业务状态。

原模块的命令行入口仍保留；直接调用旧模块不经过新对话服务的条件约束与安全过滤：

```powershell
.\.venv\Scripts\python.exe modules\m1_map.py 儿童玩具 欧盟 --no-llm
.\.venv\Scripts\python.exe modules\m2_timeline.py 儿童玩具 美国 '近 6 个月' --no-llm
.\.venv\Scripts\python.exe modules\m3_todo.py 儿童玩具 欧盟 --no-llm
.\.venv\Scripts\python.exe modules\m3_todo.py 儿童玩具 欧盟 --no-llm --export
.\.venv\Scripts\python.exe modules\m4_compare.py
```

类目入口为儿童玩具、电子电器、纺织服装、美妆个护、食品接触材料；法规市场为欧盟、美国。`标签标识`、`通用` 是横切维度，不是独立入口。M5/M6/M7提供Python `query(...)` 接口和界面入口，不保证直接运行文件会打印查询结果。

## 3. 模型理解与语音输入（可选）

已有 `.env` 应保留。首次需要模型时再复制模板：

```powershell
if (-not (Test-Path -LiteralPath '.env')) {
    Copy-Item -LiteralPath '.env.example' -Destination '.env'
}
```

编辑 `.env` 中 `MODEL_API_TOKEN`、`MODEL_API_BASE`、`MODEL_NAME`，按实际已开通的服务填写并重启。不要提交密钥、把Token写进源码，或把它拼进Git远程地址。模型未启用或调用失败时，明确产品和市场仍可由本地规则查询；可选理解开关不等同于法律审核。

语音位于折叠入口，流程是录音/上传→转写填入输入框→用户检查修改→发送。转写不直接执行法规查询；发送只使用当前文字，不重新读取音频。

云端转写需要服务单独支持 `/audio/transcriptions`，在 `.env` 配置以下四项：

```dotenv
ASR_BACKEND=cloud
ASR_API_BASE=https://你的实际服务/v1
ASR_API_KEY=你的语音服务密钥
ASR_MODEL=实际开通的语音模型
```

文本模型可用不代表语音服务可用。云端会把录音发给配置的服务。本地后端需要自行准备依赖和模型：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-asr.txt
.\.venv\Scripts\python.exe scripts\prepare_asr.py
```

用 `uv` 创建且没有pip的环境，将安装命令替换为 `uv pip install --python .venv\Scripts\python.exe -r requirements-asr.txt`。默认本地型号为 `small`；另选型号时须使准备过程与 `ASR_LOCAL_MODEL` 一致。模型下载、容器依赖、CPU延迟与准确度须在目标环境实测，本轮没有真实ASR验收。

两种后端都不可用时入口禁用，文字输入继续可用。只接受RIFF/WAVE、最大10MiB、最长60秒；单次等待上限45秒，最多2个并发任务。缓存默认关闭，超时或被调用方放弃的迟到转写不能写入缓存。本应用不另存录音，界面框架可能保留临时上传文件。

## 6. SQLite条款库与正文候选更新

配置 `COMPLIANCE_DB_PATH` 为已有库绝对路径；默认探测项目内或项目同级的 `sqlite/regulations.sqlite3`。必需表为 `laws/documents/law_documents/units`。未接库时，在资料覆盖区域显示原因，原CSV与主路线查询可用。正式库不随源码上传。

打开条款检索，输入完整CELEX或 `16 CFR Part 1250`，标题关键词可留空；多个关键词同时匹配heading。默认最多12片、24000字符，截断有提示。抽取正文未经适用性审核，不自动生成执行任务。

只抓取候选，不写库；将示例数据库路径替换为实际已有库：

```powershell
.\.venv\Scripts\python.exe scripts\sync_law_content.py --law US:16:1250 --db 'E:\实际目录\regulations.sqlite3'
.\.venv\Scripts\python.exe scripts\sync_law_content.py --law 32009L0048 --db 'E:\实际目录\regulations.sqlite3'
```

也支持 `--signals sqlite/metadata_check_latest.json` 读取元数据核验信号。候选默认位于 `data/content_staging`，包含原始响应、SHA256、正文、差异、来源和切片。人工核查版本及差异后，才应用此次真实候选与哈希：

```powershell
$lawCandidatePath = Read-Host '已审阅候选JSON路径'
$lawBodySha256 = Read-Host '确认正文SHA256'
$lawDatabasePath = Read-Host '已有SQLite库绝对路径'
.\.venv\Scripts\python.exe scripts\sync_law_content.py --apply $lawCandidatePath --confirm-sha256 $lawBodySha256 --db $lawDatabasePath
```

入库前自动生成同目录 `regulations.sqlite3.bak-UTC时间戳`，事务内同步documents、units和可用的FTS；核验原始响应哈希、正文哈希、来源、旧正文哈希及数据库一致性，异常回滚。重复应用返回unchanged，新法规保留待核对；已变化的候选须重新抓取审阅。恢复前先停止所有使用该库的服务，保留当前库，再把此次返回的真实backup复制回原数据库路径。

eCFR快照日期、修订编入日期与FR法律生效日分别保存。406、WAF、空正文或不支持的结构保留失败信息，不覆盖旧正文。本轮正式库未提供，没有核验历史约2GiB库及其全部正文；`selftest_law_store.py` 使用测试夹具。

## 7. 常见问题

- 缺少 `gradio`：用上文同一个 `.venv\Scripts\python.exe` 安装依赖和启动，检查Gradio版本为6.2.0。
- 端口占用：检查现有服务；仅为本机预览另设 `PORT`，不停止不认识的进程。
- 官方链接自动访问失败：可能是WAF、限流或本机网络；不能仅凭一次失败判法规不存在，使用真人浏览器逐条核验。
- 美国任务为空：当前57条待核对，空执行清单是审核边界，并不表示美国没有法规。
- 模型对照为空：没有真实历史回放，不会补造回答。将来回放经审查可公开后，打包才可选择 `--include-replays`。
- 魔搭上传后仍是旧界面：确认第一层入口、完整assets/core/modules/data、实际SDK配置、部署日志及当前提交，不能只看空间“运行中”。
