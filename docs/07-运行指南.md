# 怎么跑 —— ComplianceRadar 运行指南

> 这一堆 `.py` 分成三类：**能直接跑的**、**被调用的库**、**数据管线**。
> 别全都去跑，大部分是零件，不是入口。

---

## 零、先建环境（只做一次）

```bash
# 1. 建虚拟环境（本项目已建好，路径见下）
python -m venv .venv

# 2. 装依赖
.venv/Scripts/python.exe -m pip install -r requirements.txt
```

**本机已建好的环境**（推荐直接用这个）：

```
C:\Users\Kevin\.workbuddy\binaries\python\envs\default\Scripts\python.exe
```

下文用 `PY` 代表这个 python 路径，复制时替换即可。

## 一、文件分三类（先认清，少走弯路）

| 类别 | 文件 | 能不能直接跑 |
|---|---|---|
| **① 入口** | `app.py` | ✅ 启动 Web 界面 |
| | `modules/m1_map.py` | ✅ 命令行出清单 |
| | `scripts/selftest_m1.py` | ✅ 自检 26 项 |
| | `test_connection.py`、`list_models.py` | ✅ 模型链路自检 |
| **② 库（被调用，别单独跑）** | `core/corpus.py` | 语料库（有自检入口，可跑） |
| | `core/verify.py` | 引用对齐 |
| | `core/llm.py` | 模型接入 |
| | `core/__init__.py`、`modules/__init__.py` | 包声明，无内容 |
| **③ 数据管线** | `scripts/fetch_*.py` 等 8 个 | ✅ 但**仅当要更新语料时**才跑 |

> 💡 **只要用 M1，第 ② 类和第 ③ 类都不用管。** 语料已经生成好了（86 条在 `data/`）。

## 二、用 M1（最常见场景，三条命令）

```bash
cd E:/project/compliance-radar-v2

# ① 启动 Web 界面（浏览器打开 http://127.0.0.1:7860）
PY app.py

# ② 或命令行出清单（不用开浏览器）
PY modules/m1_map.py 儿童玩具 欧盟

# ③ 跑自检，确认没被改坏（26 项全绿 = 安全）
PY scripts/selftest_m1.py
```

**参数说明**（`m1_map.py`）：

| 位置 | 取值 |
|---|---|
| 第 1 个参数 | `儿童玩具` `电子电器` `纺织服装` `美妆个护` `食品接触材料` `标签标识` `通用` |
| 第 2 个参数 | `欧盟` `美国` |
| 可选开关 | `--no-llm` 跳过模型润色，直接出原始清单（**没配 Token 时加这个**） |

例：

```bash
PY modules/m1_map.py 电子电器 美国 --no-llm
```

也可以走模块方式（结果一样）：

```bash
PY -m modules.m1_map 纺织服装 欧盟 --no-llm
```

> ⚠️ 运行目录：`app.py` / `modules/m1_map.py` / `scripts/*.py` 内部都用绝对路径，
> **从哪个目录跑都行**。但建议统一在项目根目录跑，输出更整齐。

## 三、想用 AI 润色？（可选）

M1 不配 Token 也能跑（输出原始清单）。要启用「卖家提示」：

```bash
# 复制模板
cp .env.example .env
# 编辑 .env，填入 MODEL_API_TOKEN
```

然后验证链路：

```bash
PY test_connection.py    # 验证 Token 能用
PY list_models.py        # 查看可用模型列表
```

配置好之后，`app.py` 里的「启用中文卖家提示」勾选框会自动变可用。

## 三·五、想用语音输入？（可选）

语音只是「① 智能判定」页签的另一种输入方式，**不装也能跑**：装不上或没配好时，
麦克风控件自动变灰、页面提示「语音入口：未启用」，打字链路完全不受影响。

### 本地识别（默认，零密钥）

```bash
# ① 装可选依赖（含 faster-whisper + 兼容版 av，约 50MB）
PY -m pip install -r requirements-asr.txt

# ② 下模型（约 464MB，只需一次；默认走 hf-mirror 并关闭 Xet）
PY scripts/prepare_asr.py

# ③ 验证（离线可跑，23 项）
PY scripts/selftest_voice.py
```

模型落在 `C:\Users\<你>\.cache\compliance-radar\asr\faster-whisper-small`，
`core/asr.py` 会自动发现，无需配 `ASR_MODEL_DIR`。

### 云端识别（不下模型，零新增依赖）

```bash
# .env 或命令行环境变量
ASR_BACKEND=cloud
ASR_API_BASE=https://<你的服务>/v1
ASR_API_KEY=<key>
ASR_MODEL=<whisper-1 之类的模型名>
```

也可以用 `ASR_BACKEND=local|auto` 显式指定；`auto`（默认）按「有云端配置 → 云端，否则本地」选。

### 跑不通时按这三个坑排查

| 现象 | 原因 | 处理 |
|---|---|---|
| `ProxyError 502` / 一直卡住 | HuggingFace 直连不通 | `prepare_asr.py` 已默认 `HF_ENDPOINT=https://hf-mirror.com`；手工下载时自己带上 |
| `401 CAS` / Xet 存储报错 | 新版 HF 走 Xet 存储 | 加 `HF_HUB_DISABLE_XET=1`（脚本已设） |
| 模型下完了但目录是空的 | Windows 建不了缓存软链接 | 用 `local_dir` 落实体文件（`prepare_asr.py` 就是这么做的） |
| `TypeError: ... metadata_errors` | `av>=19` 移除了该参数，faster-whisper 1.2.1 还在传 | `pip install "av<19"`（已锁进 `requirements-asr.txt`） |

### 这层为什么不会污染结论

转写结果**只回填输入框**，用户确认后才走 M1.5；判定的品类/市场由确定性词典与规则识别，
法规结论 100% 来自核对语料 + `verify` 引用对齐。实测把「毛绒玩具」听成「毛绒丸具」时，
路由照样命中「儿童玩具 × 欧盟」——**转写会错字，结论不会错**。

## 四、数据管线（只有要更新法规语料时才跑）

**顺序不能乱**，前者是后者输入：

```bash
PY scripts/fetch_eu.py       # 1. 抓欧盟（EUR-Lex SPARQL）需联网
PY scripts/fetch_us.py       # 2. 抓美国（eCFR API）需联网
PY scripts/merge_corpus.py   # 3. 合并 + 去重 + 体检
PY scripts/check_links.py    # 4. 逐条实测链接
PY scripts/enrich_cn.py      # 5. 补中文名（需 .env Token）
PY scripts/make_overview.py  # 6. 生成数据总览
PY scripts/make_todo_eu.py   # 7. 生成欧盟待补清单
```

**一键跑全流程**：

```bash
run_pipeline.bat      # 双击，或命令行执行
```

> ⚠️ `check_links.py` 默认**非破坏写入**（只补空值，保留已有人工结论）。
> 要强制覆盖加 `--force`。

**管线产出**（跑完会刷新）：

```
data/eu_regulations.csv          欧盟原始抓取
data/us_regulations.csv          美国原始抓取
data/语料核对表_骨架总表.csv      合并结果
data/语料核对表_完整版.csv        ⭐ M1 读的是这个
data/数据总览.md / 骨架体检报告.txt / 链接检查报告.txt
```

## 六、常见问题

**Q：报 `ModuleNotFoundError: No module named 'openai'`**
依赖没装。跑 `.venv/Scripts/python.exe -m pip install -r requirements.txt`。

**Q：界面里法规清单有，但没有「卖家提示」**
正常——没配 `.env` 的 Token，走的是降级路径。数据完整、链接可核验，只是少了模型润色。

**Q：欧盟链接点不开**
正常。EUR-Lex 有 AWS WAF 人机验证墙，**用浏览器打开是好的**。
程序访问返回 202 不代表链接失效 —— 详见 README「关于『链接打不开』的判定规则」。

**Q：改了代码，怎么确认没破坏红线**
跑 `PY scripts/selftest_m1.py`，26 项全绿就说明引用对齐和防幻觉还好的。

**Q：`audit_guide.py` 直接跑报错**
它**必须传一个指南文件路径**（没有 `--help`）。无参数直接跑只会打印用法：

```bash
PY scripts/audit_guide.py docs/04-官方来源判定指南.md
# 或设环境变量
GUIDE_PATH=docs/04-官方来源判定指南.md PY scripts/audit_guide.py
```

**Q：`check_links.py` 会覆盖我填的核对结果吗**
不会。默认**非破坏写入**，只补空值，已有结论保留。要覆盖得显式加 `--force`。
